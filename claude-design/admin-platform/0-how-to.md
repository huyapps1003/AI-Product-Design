## Steps

1. Use the same Claude Design project as the other modules, so MinV and the earlier screens are already there.
2. Attach the two files.
3. Paste Prompt 1. It builds the OWIS Digital Campus setup run.
4. Add one screen at a time with the follow-ups: module switch-on, users and one user's access, roles and templates, support session approval, access review, data protection, audit.
5. Check each round against the review checklist.
