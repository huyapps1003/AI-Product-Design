All people and numbers are invented.

## Steps

1. Use the same Claude Design project as Student Directory and Admissions, so MinV and the earlier screens are already there.
2. Attach the two files (the Student Directory and Admissions files can stay attached).
3. Paste Prompt 1. It builds the class overview, the class detail for 7B and the class plan.
4. Add one screen at a time with the follow-ups: needs a class, class move with an over-limit check, rollover, houses, teacher view, settings "Not set".
5. Check each round against the review checklist.

## Limits

- Section 6 of the brief lists what is still open (who allocates, size limits, what parents see, house rules, streams). Show those as "Pending decision".
- Class size limits and house lists are each campus's own settings, not group defaults.
- DL-70…DL-76 are Confirmed (14 Nov 2026).
